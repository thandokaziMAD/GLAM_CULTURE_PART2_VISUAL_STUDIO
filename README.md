## How to open in Visual Studio Code
1. Extract the ZIP.
2. Open Visual Studio Code and choose **File > Open Folder**.
3. Select the **DISD GLAM CULTURE** folder.
4. Open `home.html`.
5. Preview it in your browser. Live Server can also be used if it is installed.

## Part 2 features added
- External `style.css` linked to all five pages.
- CSS reset and consistent base typography, colours, spacing and sizing.
- Flexbox navigation and CSS Grid page layouts.
- Borders, shadows, rounded cards, hover, focus and active states.
- Desktop, tablet and mobile breakpoints using media queries.
- Relative units including `%`, `rem`, `vw` and `clamp()`.
- Responsive homepage images using `picture`, `srcset` and `sizes`.
- Mobile navigation, scroll reveal and contact-form feedback.
- Accessibility improvements including labels, alt text, focus states and reduced-motion support.
- Corrected the broken `gallary.html` links to `gallery.html`.

- Tablet: about 820 px wide

Place the screenshots in the `screenshots` folder and include them in the README/repository as required by the brief.
